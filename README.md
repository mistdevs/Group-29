Setup Instructions

1. Open XAMPP.

2. Start Apache and MySQL.

3. Open phpMyAdmin.

4. Create a new database named uums_db.

5. Import the provided SQL file into uums_db.

6. Place the project folder inside the htdocs directory.

7. Open your browser and go to:

http://localhost/u-ums/


*** Make sure the folder name inside htdocs matches u-ums.
